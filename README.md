# Pokémon Carmine

A full-stack Pokémon-inspired web game where players can choose a starter, catch Pokémon, build a collection, and manage their profile.

**[Live Demo](https://pok-mon-carmine.vercel.app/)** · **[Report a Bug](https://github.com/rahulbaghelp01/Pok-mon-Carmine/issues)**

## Features

- JWT authentication with bcrypt password hashing
- Starter Pokémon selection and catching gameplay
- Pokémon collection and deck management
- User profiles and protected routes
- Interactive 3D Pokéball and animated cards
- Responsive UI and global state management

## Tech Stack

- **Frontend:** React, Vite, React Router, Redux Toolkit, Tailwind CSS
- **3D & Animation:** Three.js, React Three Fiber, Drei, GSAP
- **Backend:** Node.js, Express.js, JWT, bcrypt
- **Database:** PostgreSQL, Prisma ORM
- **Tools:** Docker, Git, GitHub, Vercel

## Gameplay Flow

`Create Account → Choose Starter → Catch Pokémon → Build Collection`

## What I Learned

I built this project to go beyond basic CRUD applications and explore interactive web experiences.

- Full-stack application architecture
- Authentication and relational database design
- 3D rendering and animations in React
- State management and API integration
- Debugging and deployment
